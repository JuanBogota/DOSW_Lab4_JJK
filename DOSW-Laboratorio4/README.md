###### a. ¿Qué es un arquetipo (Archetype) en Maven?

Un arquetipo en maven es un modelo de proyecto ya configurado, es decir, una plantilla que se usa para 	crear 	una estructura básica de un proyecto ya con configuraciones y dependencias que son muy communes en los proyectos de software. 

###### b. ¿Para qué sirve el arquetipo maven-archetype-quickstart?

Este arquetipo es una plantilla básica que crea un proyecto java con una estrucutura predeterminada. Sirve para crear una clase principal llamada App.java y la clase test de App.java, llamada AppTest.java.

###### c. ¿Cuál es el comando con el cual se puede crear un proyecto basado en

###### un arquetipo maven?

Para crear un proyecto basado en el arqueotipo maven se usa el commando: mvn archetype:generate -DgroupId=edu.dosw.lab -DartifactId=DOSW-Laboratorio4 -DarchetypeArtifactId=maven-archetype-quickstart -DinteractiveMode=false

###### d. ¿Qué es un pull request en GitHub?

Un pull resquest en GitHub es una solicitud para fusionar cambios de una rama a otra, la idea es que los otros miembros del equipo revisen los cambios y decidan si integrarlos al proyecto principal.

###### e. ¿Cómo se crea un pull request en GitHub?

En GitHub creamos un pull request desde la pagina del repositorio, en la pestaña Pull requests, después en el botón verde "New pull request", se selecciona la rama que se desea fusionar con la rama base, se escribe la descripción de los cambios y se envía el nuevo pull request.

###### f. ¿Cómo se aprueba un pull request en GitHub?

La idea es que un integrante del equipo, diferente al que hizo el pull request, revise los cambios y si todo está bien, le da al botón "Approve" en la pagina de GitHub.
